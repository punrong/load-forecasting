# Load Forecasting with the HUE Dataset

Short-term residential load forecasting using the HUE dataset (hourly electricity consumption of 28 households in British Columbia, Canada), combined with weather and holiday features.

> **Status:** work in progress. The data preprocessing pipeline is in place; modeling is planned next.

## Repository Structure

```
load-forecasting/
├── data/                      # Raw input files (see "Data" below)
├── data-preprocessing.ipynb   # Cleaning, feature engineering, and merging
├── requirements.txt           # Python dependencies
└── README.md
```
